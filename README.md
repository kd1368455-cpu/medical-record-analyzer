# Medical Record Analyzer

## 概要
電子カルテや検査結果を想定した医療データを解析し、  
**欠損値補完・型チェック・異常値検知・レポート出力** を行う Python ツールです。

医療システム開発で求められる  
**「データ前処理」「異常値判定」「ログ管理」** を再現しており、  
実務に近い処理フローを意識して構築しています。

---

## 使用技術
- Python  
- pandas  
- logging（業務向けログ出力）

---

## 主な機能

### ✔ 欠損値補完（中央値）
検査データの欠損値を自動で補完し、  
医療データで頻出する「欠損のあるデータ」を扱えるようにしています。

### ✔ 型チェック
数値項目に文字列などが混入していないかを検証。  
医療システムで重要な **データ品質チェック** を再現。

### ✔ 異常値検知
- **高血圧疑い**（収縮期 140 以上 or 拡張期 90 以上）  
- **高血糖疑い**（血糖値 140 以上）  

医療現場でよく使われる基準を元に判定。

### ✔ ログ出力
- 処理開始/終了  
- 欠損値補完  
- 異常値検知  

実務で使われるログ形式を採用。

### ✔ レポート出力
- 患者数  
- 高血圧疑い人数  
- 高血糖疑い人数  
- 患者別の判定結果  

---

## 工夫した点
- 医療データ特有の **欠損値処理** を実装  
- pandas による **業務向けデータ前処理**  
- logging による **実務レベルのログ管理**  
- 異常値判定ロジックを関数化し、保守性を向上  
- 電子カルテを想定した **患者単位のレポート出力**
